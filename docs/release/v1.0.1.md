# test-lang v1.0.1

A patch release. There are no API changes.

## Fixed

- **Diff memory is bounded.** `Diff::lines` builds a table with one `u32` per pair of changed lines. It had no limit, so two 8,000-line texts that differ at both ends took 244 MiB, and larger ones could run out of memory instead of reporting a mismatch. The table is now capped at 4 Mi cells (16 MiB, a changed region of about 2,000 by 2,000 lines). A larger changed region is reported as deleted and then inserted in full. That is still a correct diff, just not a minimal one.

## Changed

- `Snapshot::check` compares the normalized text first and builds a diff only when it does not match, so a passing check no longer copies every line.
- The docs for `Snapshot::per_line` now say that items are normalized like any snapshot text: an item that renders as only spaces or tabs becomes a blank line. Render whitespace tokens visibly, for example through `Debug`, if they matter.

MSRV is unchanged at Rust 1.85.
